## 📖 About

This repository hosts the source code for Nikesh Paudel's official personal website, built as a static site and served for free via **GitHub Pages**. The site shares his work as a motivational speaker, life coach, author, and poet, along with ways to connect and book sessions.

## 📁 Pages

| Page | File | Description |
|---|---|---|
| Home | `index.html` | Landing page / introduction |
| About | `about.html` | About Nikesh Paudel |
| Blog | `blog.html` | Articles and insights |
| Contact | `contact.html` | Contact & booking inquiries |
| Privacy Policy | `privacy-policy.html` | How visitor data is collected and used |
| Terms & Conditions | `terms-and-conditions.html` | Terms of use for the website |
| 404 | `404.html` | Custom "page not found" screen |

## 🛠️ Built With

- **HTML5 / CSS3** — semantic markup with a glassmorphism-inspired design
- **[DM Sans](https://fonts.google.com/specimen/DM+Sans) & [Playfair Display](https://fonts.google.com/specimen/Playfair+Display)** — Google Fonts
- **[Font Awesome 6](https://fontawesome.com/)** — icons
- **GitHub Pages** — static hosting

No build step or framework is required — every page is a self-contained static HTML file.

## 🚀 Local Development

Clone the repo and open any page directly in a browser, or serve it locally:

```bash
git clone https://github.com/nikeshpaudel/nikeshpaudel.github.io.git
cd nikeshpaudel.github.io
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## 🌍 Deployment

The site is automatically published via **GitHub Pages** from the `main` branch. Any change pushed to `main` goes live at [nikeshpaudel.github.io](https://nikeshpaudel.github.io) within a few minutes.
